# 家宴点单 v0.2.5

发布日期：2026-08-12

## 本次更新

### 关于项目页新增更新日志

- "关于项目"页面的版本号变为可点击入口（悬停有虚线下划线提示，下方标注"点击查看更新日志"），点击弹出**更新日志**弹窗。
- 弹窗从 GitHub Releases 拉取全部历史版本（最多 20 个），按时间倒序展示每个版本的发布日期与发布说明，说明使用与"检查更新"卡片相同的 Markdown 渲染（`renderMarkdown`）。
- 每个版本条目右上角提供"在 GitHub 查看 →"链接，可直接跳转到对应 Release。
- 新增后端接口 `/api/update/changelog`，复用 10 分钟内存缓存，避免频繁请求 GitHub API。
- 内容过多时弹窗内滚动，不撑破窗口。

## 升级说明

普通 Node.js 部署更新代码后需要重启服务：

```powershell
node server.js
```

Docker 或 NAS 部署请重新构建并启动容器：

```bash
docker compose up -d --build
```
