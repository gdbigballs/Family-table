# 家宴点单 v0.2.4

发布日期：2026-08-12

## 本次更新

### 更新弹窗支持 Markdown 渲染

- "检查更新"弹窗中的发布说明（GitHub Release Notes）由纯文本改为 Markdown 渲染，标题、列表、粗体、代码块、链接等样式清晰可读。
- 新增零依赖的轻量渲染器 `renderMarkdown()`（`public/app.js`），不引入第三方库，保持项目零依赖与离线可用。
- 支持的语法：`#` 标题（映射为 h3-h6）、无序/有序列表、`**粗体**`、行内代码、围栏代码块、`[链接](url)`、段落。
- 安全性：内容先整体 HTML 转义再渲染标记；链接仅允许 `http/https` 协议，`javascript:` 等伪协议链接会被剥离；行内代码内的标记不做二次渲染。
- 更新卡片补充对应样式（`public/styles.css`），内容过长时卡片内滚动，不撑破弹窗。

## 升级说明

普通 Node.js 部署更新代码后需要重启服务：

```powershell
node server.js
```

Docker 或 NAS 部署请重新构建并启动容器：

```bash
docker compose up -d --build
```
