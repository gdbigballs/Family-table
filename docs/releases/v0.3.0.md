# 家宴点单 v0.3.0

发布日期：2026-08-12

## 本次更新

本版本聚焦管理后台的体验优化与代码重构，并对移动端做了整体重做。

### 后台体验

- **移动端底部导航**：后台在手机上改为底部 Tab 栏（概览 / 订单 / 菜单 / 更多），高频入口直达，"更多"抽屉收纳点评、图片、设置、导入导出、关于等低频页面；顶部不再横向滚动 8 个 tab。
- **订单列表卡片化**：后台订单列表在手机上从横向滚动表格改为卡片式布局（状态、时间、菜品、联系人分块展示，操作按钮通栏）。
- **菜单管理卡片化**：菜品表格在手机上同样改为卡片布局；分类筛选与管理收进抽屉，不再在顶部堆叠横向滑动的分类栏。
- **分类管理升级**：分类改名后失焦自动保存；排序支持连续点击 ↑↓ 本地调整、最后统一"保存顺序"；支持删除分类（有菜品的分类点击时会明确提示原因，不再静默禁用）。
- **营业状态卡**：概览页营业状态卡重排——状态圆点内联在"营业中"文字旁，并新增"调整预约与营业"直达入口，一键进入预约规则设置。
- **局部刷新**：后台所有操作（切换页面、处理订单、维护菜单等）只刷新内容区，不再整页重建，避免滚动位置与输入焦点丢失。
- **无障碍**：后台导航补全 ARIA 语义（tablist / tab / tabpanel / aria-selected），并增加键盘导航焦点样式。

### 功能调整

- **移除管理员备注**：该功能服务端本就不写入、不返回，属半失效状态，已从前端彻底移除。
- **订单状态机统一**：移除已废弃的"制作中 / 已取消"状态（服务端启动时已自动迁移为"已确认 / 已拒绝"），概览统计、筛选选项与操作按钮口径一致。

### 代码重构

- 清理 `app.js` 中约 500 行历史遗留死代码，展开全部"函数覆盖链"，前后台逻辑结构清晰、更易维护。
- 修复一个历史 bug：新增/编辑菜品时规格属性无法保存（弹窗与保存逻辑不匹配），已恢复属性编辑器。

## 升级说明

普通 Node.js 部署更新代码后需要重启服务：

```powershell
node server.js
```

Docker 部署重新构建并重启：

```bash
docker compose up -d --build
```

数据无需迁移；启动时服务会自动把历史"制作中 / 已取消"订单迁移为"已确认 / 已拒绝"。建议更新前先备份 `data/` 目录。
