# 家宴点单 v0.2.0

发布日期：2026-08-05

## 本次更新

### 首页信息卡片

- 重做移动端首页顶部卡片，压缩留白并固定为“标题、每日一言、插画、营业状态、当前菜单”的紧凑布局。
- 每日一言与插画采用左右网格排列，避免不同长度的文案影响插画位置。
- 营业状态与当前菜单统计调整为底部双栏；当前菜单会自动显示已上架分类数和菜品数。
- 新增锅与米饭插画资源，作为首页信息卡片的视觉内容。
- 桌面端首页顶部卡片改为三列：左侧每日一言、中间插画、右侧营业状态和当前菜单统计。
- README 页面预览更新为当前版本的桌面菜单、移动端菜单、移动端菜品卡片和移动端确认下单截图。

### 每日一言

- 每次访问首页都会直接请求一言 API，不再复用前端状态或服务端缓存。
- `/api/daily-quote` 响应设置为 `Cache-Control: no-store`。
- 根据文案长度自动缩小字体，避免长句被两行裁切。
- 出处仅显示作者或来源名称，并修正加载提示和出处颜色过浅的问题。

### 点菜与下单体验

- 优化菜品卡片的信息层级，调整图片、评分、点单次数、菜名和简介的展示关系，便于快速比较菜品。
- 优化确认下单界面，完善立即点菜与预约用餐的填写和切换流程。
- 优化移动端菜单浏览：分类栏会在菜单区域固定显示并随滚动高亮当前分类；菜品卡片适配单列布局，保持图片、文字和统计信息清晰可读。

## 升级说明

本次更新不涉及数据库结构变更。

普通 Node.js 部署更新代码后需要重启服务，使每日一言接口的无缓存逻辑生效：

```powershell
node server.js
```

Docker 或 NAS 部署请重新构建并启动容器：

```bash
docker compose up -d --build
```
