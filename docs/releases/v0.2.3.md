# 家宴点单 v0.2.3

发布日期：2026-08-12

## 本次更新

### 下单与点评接口限流

- 新增通用滑动窗口限流工具（server.js）：按客户端 IP 计数，超限返回 HTTP 429 并携带 `Retry-After` 响应头。
- 下单接口（`/api/order`、`/api/immediate-order`）新增限流：同一 IP 10 分钟内最多提交 3 单，防止脚本刷单导致数据库膨胀和企业微信通知轰炸。
- 点评接口保持原有阈值不变（同一 IP 15 分钟最多 3 条），切换至通用限流实现，行为一致。
- 客户端 IP 优先解析 `X-Forwarded-For` 请求头：反代部署下不再把反代 IP 误当成真实访客，也不会让同一反代后的所有访客共享计数导致误伤。
- 限流计数自带过期清理，Map 超过阈值时全量清理，不再随访问量无限占用内存。

### 下单幂等（防重复提交）

- 前端提交订单时自动附带一次性 `requestId`（`crypto.randomUUID`，局域网 HTTP 环境自动回退）。
- 服务端对同一 `requestId` 15 分钟内只处理一次：重复提交直接返回第一次的订单编号与查询凭证，不再写入数据库、不再重复发送企业微信通知。
- 手抖双击、网络重试、脚本重放都不会产生重复订单。

### 说明

- 本次不涉及数据库结构变更，无需备份或迁移。
- 限流与幂等计数存于内存，服务重启即重置（对家庭场景足够，无需引入 Redis）。

## 升级说明

普通 Node.js 部署更新代码后需要重启服务：

```powershell
node server.js
```

Docker 或 NAS 部署请重新构建并启动容器：

```bash
docker compose up -d --build
```
